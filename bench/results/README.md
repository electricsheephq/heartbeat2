# Deterministic simulation results

Run `.venv/bin/python -m bench.run --baseline --gate --out /path/to/artifacts`.
`--scenario ID` runs one scenario. Only this README and `.gitkeep` belong here;
JSON and Markdown results are generated artifacts, not committed measurements.
Claim class: deterministic simulation on this suite (advisory), not live delivery.
The naive heartbeat-1.0 emulator is built from documented failure reports; not
current OpenClaw (which retired HEARTBEAT.md in 2026.8.1). Its numbers are never
measurements of OpenClaw.
